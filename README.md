# Volley Deník (PWA Aplikace)

Osobní volejbalový deník a kalendář pro plánování tréninků, zápasů a hodnocení herních výkonů.

## Složka obsahuje:
- `index.html` - Hlavní kód aplikace (Kalendář, Formuláře, Statistiky, PWA rozhraní)
- `manifest.json` - PWA Manifest pro instalaci na plochu
- `sw.js` - Service Worker pro kompletní offline provoz
- `icons/` - Ikony v rozlišeních 180x180 (Apple), 192x192, 512x512 a maskovatelná ikona

## Jak spustit:
1. Rozbalte soubor ZIP na svém počítači nebo webovém serveru.
2. Otevřete `index.html` v libovolném moderním prohlížeči (Chrome, Safari, Edge, Firefox).
3. Pro plnou PWA funkcionalitu (instalace na plochu) hostujte soubory na jakémkoliv webovém serveru nebo local-hostu (např. GitHub Pages, Vercel, Netlify, Live Server).
